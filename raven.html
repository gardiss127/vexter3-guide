5. Raven & Epigraphs

Recommended roadmap
WORKSHOP 15 → MAIN FACTION → 4-ROLE PURPLE SET → STAR DUPLICATES → EVOLVE 2+ → SQUAD 2 → GOLD LATER

Raven progression

Raven progression includes leveling/attributes, Raven gear, Evolution, and Epigraphs. Raven upgrades are valuable because they can support more than one squad. A useful early Raven leveling target is around Level 110, where the initial skill milestone path reaches its listed endpoint.

Save Raven Fruit and Raven Essence for Monday / Enhance Raven. Raven has eight gear slots; some pieces improve hero stats. Save Raven Gear Chests for Wednesday / Tech Researchunder the VEXTER3 Alliance Duel schedule.

Epigraph Workshop

Bring the Epigraph Workshop to Level 15so you can craft purple Epigraphs. Then identify the faction used by your main march and build the four-role purple set for Squad 1.

Finish the primary set before branching out

Star up useful duplicates before chasing gold crafts. Do not start heavily investing in Squad 2 until you have Evolve 2+and your primary set is finished. If you mis-craft an Epigraph for the wrong faction, reset it instead of leaving those resources stranded.

Gold comes later
A complete, developed purple setup for your primary squad is the goal before expensive gold chasing or spreading resources to secondary squads.

5. Corbeau & Épigraphes

Plan recommandé
ATELIER 15 → FACTION PRINCIPALE → SET VIOLET 4 RÔLES → ÉTOILES SUR DOUBLONS → ÉVOLUTION 2+ → ESCOUADE 2 → OR PLUS TARD

La progression du Corbeau comprend les niveaux/attributs, l'équipement, l'Évolution et les Épigraphes. Les améliorations du Corbeau sont utiles car elles peuvent soutenir plusieurs escouades. Un bon premier objectif est d'avancer vers le niveau 110.

Gardez les Fruits du Corbeau et l'Essence du Corbeau pour lundi / Amélioration du Corbeau. Gardez les Coffres d'équipement du Corbeau pour mercredi / Recherche technologique.

Atelier d'Épigraphes

Montez l'Atelier au niveau 15pour fabriquer des Épigraphes violettes. Identifiez ensuite la faction de votre marche principale et fabriquez le set violet complet de quatre rôles pour l'Escouade 1.

Terminez le set principal

Montez les étoiles avec les doublons utiles avant de courir après l'or. N'investissez fortement dans l'Escouade 2 qu'après Évolution 2+et un set principal terminé. Si vous fabriquez une Épigraphe pour la mauvaise faction, réinitialisez-la.

L'or vient plus tard
Un set violet complet et développé pour votre escouade principale passe avant la chasse coûteuse aux fabrications or.
