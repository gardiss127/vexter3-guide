# Hero Library V2 — User-Confirmed Profile Standards

These requirements were explicitly confirmed by the user on November 11, 2026. Apply to every new profile; do not import legacy hero profiles.

## Original portrait
- Each hero uses the exact character portrait supplied by the user. Do not generate, substitute, or retrieve a different portrait.

## Required profile content
1. Brief character description.
2. Faction: Warrior, Ranger, or Warlock (user's message said 'warrior, ranger, tank'; tank is a **role**, not a faction, per prior roster conventions; confirm any ambiguity when relevant).
3. Role: Tank, DPS, or Support.
4. Descriptions of individual skills, **without damage numbers or level-dependent numerical values** (they change with skill level).
5. Recommended skill upgrade priority.
6. Recommended gear priority.
7. Recommended team composition: **two tanks in front; two DPS and one support in back**.

## Exclusive Weapon
Only Daskal, Louis, and Ulfrid have Exclusive Weapons. No other hero should have an Exclusive Weapon section.

## Awakening
Only Marlena, Cynthia, and Annie have Awakening. No other hero should have an Awakening section.

## Workflow
- Start with UR heroes.
- Draft only from newly supplied images and user confirmations.
- Obtain explicit user approval, then save the completed hero profile and exact portrait in the V2 master before moving on.
- Do not change live `main` or recycle the old Hero Library.
