12. KvK / SvS

First instruction
READ THE ALLIANCE NOTICE BEFORE THE BATTLE. The King and server leadership can change the plan, locations, targets, and the alliance's role.

As a general guideline, squads under 17Mshould not join Castle rallies unless leadership specifically directs otherwise.

If base hits are NOT allowed

Under-17M players can contribute through Turret ralliesinstead of Castle rallies, following the current battle call.

If base hits ARE allowed

Players who are actively fighting can group in the mud for PvP. Players who are not fighting should remain in the grass under shieldand can reinforce the fighters when requested.

RALLY ATTACKS ONLY. NO SOLO ATTACKS.

The static guide never replaces the current server plan. If the alliance notice says something different for a specific battle, follow the notice.

12. KvK / SvS

Première instruction
LISEZ L'AVIS DE L'ALLIANCE AVANT LA BATAILLE. Le Roi et le leadership du serveur peuvent modifier le plan, les cibles et le rôle de l'alliance.

En règle générale, les escouades de moins de 17Mne rejoignent pas les rallyes du Château sauf instruction spécifique.

Si les attaques de bases sont interdites: les joueurs sous 17M peuvent contribuer avec les rallyes de Tourelles selon l'appel actuel.

Si les attaques de bases sont autorisées: les combattants peuvent se regrouper dans la boue pour le PvP. Les non-combattants restent dans l'herbe sous bouclieret renforcent les combattants lorsque demandé.

ATTAQUES EN RALLYE UNIQUEMENT. PAS D'ATTAQUES SOLO.
